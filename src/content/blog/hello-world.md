## How posts work

Each post is a markdown file in `src/content/blog/`. Publishing is:

1. Write a markdown file with `title`, `date`, and an optional `description` in the frontmatter.
2. Commit it.
3. Run the deploy command.

```bash
npm run deploy
```

That's it.
